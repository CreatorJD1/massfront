# Retired native iOS wrapper

Native iOS delivery was permanently retired by the owner on 2026-08-31.
MASSFRONT is delivered to iPhone and iPad as a browser-installable Safari PWA.

This directory is retained only as frozen historical source. It is not an
active release target and must not be versioned, synced, built, signed, tested
as a native package, added to release-source archives, or published. Current
Apple-device verification covers the installed Safari PWA, including WebKit,
safe-area, rotation, audio-codec, storage, offline, and Add-to-Home-Screen
behavior.
