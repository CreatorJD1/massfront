## Product direction

MASSFRONT is a touch-first large-scale RTS/RPG with readable tower-defense
preparation, combined-arms counters, persistent commander progression, and four
visually and mechanically distinct factions. Current status is **Pre-Alpha**.
Do not market the build as beta or complete.

Canonical faction aliases:

- Terran Frontline Command = Nova/player faction.
- Crimson Dominion = Red Ascendancy/Legion.
- Syndicate Coalition = Machine Ascendancy/Emerald Triad.
- Brood Swarm = Umbral Brood/Infestation Swarm/Void Swarm.

The Brood is entirely biological. Never give it manufactured vehicles, panels,
barrels, engines, or machine factories. The Syndicate owns the most advanced
energy, autonomous, hover, phase, and predictive-control technology.

## v1.32 player-facing delta

- Three real skirmish sizes: Compact (1.9 km), Standard (2.2 km), and Large
  (2.6 km), with different match estimates, resources, spacing, and hazards.
- Four deterministic non-square battlefield silhouettes. The red holographic
  line marks the playable edge; coastline/wasteland continues beyond it as
  atmospheric fake terrain. Movement, patrols, rally points, formation drops,
  structures, starts, resources, cities, nests, pickups, and AI construction
  remain inside the line.
- Mobile top HUD uses safe rows and 44 px or larger speed/pause controls.
- Atlas Skycrane is a buildable 12-slot Terran air transport. Eligible selected
  infantry, constructors, miners, and light vehicles board by approaching the
  carrier; heavy armor, artillery, Titans, aircraft, and ships are rejected.
  Cargo keeps health, veterancy, kills, modes, and cooldowns. Drop zones show a
  formation hologram, and carrier destruction destroys stored cargo.
- Syndicate Phase Ark is the faction-specific buildable transport art: a
  cockpitless tailless energy delta with a phase aperture, not a recolored
  Skycrane.
- Brood Massflesh is a real AI breakthrough threat and Brood-only production
  unit. It absorbs an eligible light brood into 18 biomass, changes from a
  ground-heavy/anti-tank-countered siege organism into a 26-second airborne/
  anti-air-countered form, attacks light units and structures with tentacles,
  and births the stored tide behind defenses. Its warning is persistent and
  tap-to-track. The visual target is an original vertical cephalopod organism:
  armored cranial halo, exposed lift/neural sac, and hanging hooked tendrils.
- Resource fields, cities, nests, crates, tanks, and AI structures were audited
  across all three sizes; no live objective footprint escapes the playable map.

## Architecture and release rules

- Canonical source is `index.html`, `boot.js`, `src/**`, and `assets/**`.
- Scripts are classic scripts in one global lexical scope. Do not add modules.
  Duplicate top-level `const`/`let` names are fatal.
- Script order is duplicated in `boot.js` and `assets/data/manifest.json`; keep
  the lists identical and dependency ordered.
- Run `node tools/bundle.mjs` after every source edit.
- Never hand-edit `dist/**`, `www/**`, or native `public/**`; regenerate them.
- Unit slots recycle. Any delayed unit reference must retain `(slot, ugen)`.
- Package Android with `assembleInstallable`, then `tools/shrink-apk.ps1`.
  Package ID is `com.creatorjd.massfront.mobile`; established signer SHA-256 is
  `D61AAF77C171F0F1E7841394EB0ADAED196E146AD90226A0F07854C29EE073F0`.
- Active release channel is Hugging Face dataset
  `CREATORJD/massfront-releases`; live web is static Space
  `CREATORJD/massfront-playtest`. Upload immutable payload/artifacts first and
  update `update.json` last.
- A Windows-generated iOS wrapper is valid source, but no IPA is installable
  without an authenticated Apple signing workflow on macOS/cloud hardware.

8. Server-authoritative progression remains the highest-risk commercial task;
   currency is still client-side until the existing economy worker is deployed.

## Known release risks

- Real-device large-battle performance and AAC playback still need hardware
  validation.
- Some Nova, Red, and Syndicate roles still share baseline chassis beneath
  doctrine overlays.
- The Massflesh uses a first production-quality procedural model, not a final
  sculpted/baked hero asset.
- A signed IPA is not included.
- Audio ownership was asserted by the owner, but receipt/vendor/license fields
  still need durable commercial documentation.
