# MASSFRONT v1.32.2 — Branding Hotfix Handoff

## Scope

This is a deliberately small branding update. It changes only:

1. The app icon, sourced from the supplied four-faction MASSFRONT artwork.
2. Launch and splash-title artwork, sourced from the supplied horizontal MASSFRONT wordmark.

Do not include gameplay, balance, UI-system, audio, account, updater, or content changes in this release.

## Delivery boundary

### OTA / browser update

The HTML launch/title reveal can ship in the small OTA and browser deployment. `tools/bundle-update.mjs` embeds the HTML shell, CSS, and JavaScript, but it does **not** automatically embed new binary art. Add the new versioned title-art file to its `otaBinaryAssets` list (or inline it intentionally) so an already-installed build receives the actual bitmap instead of a missing-file reference.

Run:

```bash
node tools/bundle.mjs
node tools/pack-www.mjs
node tools/bundle-update.mjs 1.32.2
```

Do not edit generated copies in `www/`, `android/app/src/main/assets/public/`, or `ios/App/App/public/`; regenerate them using the normal packaging flow.

### Native package update

An installed Android/iOS launcher icon and OS-controlled launch screen cannot be changed by OTA. The native paths above require a newly signed Android APK (and a signed iOS build when credentials are available). The APK must use the existing package identity and signing certificate for an in-place update.

After Android icon/splash changes:

```bash
npx cap sync android
cd android && ./gradlew assembleInstallable --offline
cd .. && powershell -ExecutionPolicy Bypass -File tools/shrink-apk.ps1
```
