# Hero Planet Image-Generation Prompts

These are the exact built-in image-generation prompts used on 2026-08-20.
Each output is an original, project-bound 2:1 color-material source; no supplied
game screenshot is present in a runtime texture.

## Caldris

```text
Use case: stylized-concept
Asset type: production source texture for a physically based 3D hero planet in a realistic science-fiction exploration game
Primary request: a seamless equirectangular satellite-color surface atlas for Caldris, an oceanic UGA biosphere-preserve world
Subject: deep teal oceans, intricate cyan shallows, continental archipelagos, pale mineral shelf lines, sparse green-brown landmasses, believable tectonic and erosion structure
Style/medium: photorealistic orbital remote-sensing texture, natural geological detail at macro and micro scales, presentation-ready game material source
Composition/framing: flat 2:1 equirectangular world-surface map filling the canvas edge to edge, horizontally seamless, pole-safe detail, no perspective
Lighting/mood: neutral diffuse material capture with absolutely no directional lighting, limb shading, atmosphere, bloom, or cast shadows
Color palette: deep navy and teal water, muted mineral cyan, restrained olive and umber land
Materials/textures: high-frequency coastlines, continental shelf sediment, reef chains, trenches, weathered rock grain
Constraints: original MASSFRONT material; no planet sphere, no space, no stars, no clouds, no labels, no text, no logos, no watermark; left and right edges must tile; no obvious central focal feature; suitable for deriving height, normal, roughness, AO, and emissive maps
Avoid: generic blue-marble Earth copy, painted concept-art brushwork, baked highlights, visible seams, UI elements
```
