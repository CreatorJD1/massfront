# MASSFRONT 32-Planet Spline Prompt Catalog

**Status:** source authoring prompts only; `runtimeReady:false`.

This catalog contains 32 distinct planet guides. Each guide has one orbital/war-table prompt and eight named ground-location prompts, for 288 prompts total. A prompt or Spline scene is not runtime implementation evidence.

Use one prompt block at a time in a deliberately selected Spline 3D document. Read [PLANET_32_GUIDE_CONTRACT.md](PLANET_32_GUIDE_CONTRACT.md) and the shared [PROMPT_GUIDE_CONTRACT.md](../PROMPT_GUIDE_CONTRACT.md) first.

The four existing save-stable homeworlds are marked **Canon**. The remaining 28 are **Expansion proposals** and must not enter runtime catalogs until separately approved.
